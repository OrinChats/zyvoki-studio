Importar / atualizar projeto

Receba um novo ZIP do projeto e importe aqui. Não precisa publicar o site de novo. O último projeto fica salvo neste navegador.

ZIP aceito: pasta film/ com index.html e scripts .js, mais áudio .mp3/.wav/.m4a na raiz ou em audio/. Importe apenas projetos de fontes confiáveis.

Exportar vídeo

Grave a animação diretamente pelo Chrome. Mantenha esta aba aberta e a tela ligada até terminar. A exportação usa WebM; a disponibilidade depende do navegador Android.

⬇ Baixar vídeo WebM

MP4 ainda não está disponível nesta versão. Para máxima compatibilidade, recomendamos publicar o site e usar Chrome atualizado.

Como usar no celular

1. Publique esta pasta no Vercel ou em uma hospedagem estática.
2. Abra o endereço pelo Chrome.
3. Assista, pause e arraste a linha do tempo.
4. Toque em “Gravar vídeo” para tentar salvar o WebM.
